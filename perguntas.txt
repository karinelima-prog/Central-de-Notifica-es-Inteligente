1. O que é um Toast e qual sua finalidade?

É uma notificação que aparece na tela para avisar o usuário quando alguma ação é realizada.

2. Qual é a principal diferença entre um Toast e um Modal?

O Toast mostra uma mensagem rápida que desaparece sozinha, já o Modal abre uma janela maior na tela.

3. O Toast aparece automaticamente ou precisa ser ativado?

Precisa ser ativado pelo JavaScript quando o usuário clica em um botão.

4. Qual instrução JavaScript permite criar uma instância de Toast?

new bootstrap.Toast(elemento).

5. Para que serve o método .show()?

Serve para fazer a notificação aparecer na tela.

6. O que significa a opção autohide?

Significa que a notificação fecha sozinha depois de alguns segundos.

7. Qual é a finalidade de delay?

Serve para definir quanto tempo a notificação vai ficar aparecendo na tela.
